## 0.1.0

 - Initial release of `forui_firebase_ui_shared`: Forui port of the original Firebase UI shared widgets (`FButton`, `FCircularProgress`, `FDialog`, and related helpers). Requires an `FTheme` ancestor and Dart `^3.13.0` / Flutter 3.47+.
