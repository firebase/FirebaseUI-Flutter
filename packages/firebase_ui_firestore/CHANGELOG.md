## 0.1.0

 - Initial release of `forui_firebase_ui_firestore`: Forui-compatible port of the original Firebase UI Firestore package. Query list/grid loading uses Forui-backed indicators via `forui_firebase_ui_shared`. `FirestoreDataTable` remains Material-based. Apps using Forui widgets must wrap UI in an `FTheme` ancestor. Requires Dart `^3.13.0` / Flutter 3.47+.
